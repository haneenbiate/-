# تعليمات مراجعة NASN — المعنى ونطاق النفي

هذه مراجعة بشرية مستقلة. افتح ملف HTML في المتصفح بدون إنترنت، وأدخل هوية
مراجع مميزة. لا تتناقش مع المراجع الآخر قبل إكمال قراراتك، ولا تستعمل تنبؤات
النموذج للحكم على المعنى. النصوص من مجموعة التحقق فقط.

قارن النص الأصلي والمعدّل: هل بقي المعنى والمشاعر؟ انتبه إلى التهكم واللهجة
والأسماء والكيانات والتأكيد ونطاق النفي. زيادة تكرار حرف قد تغيّر التأكيد؛
لا تفترض أن جميع التحويلات صحيحة. إذا لم تكن متأكدًا، سجّل الغموض.

| الحقل | الخيارات |
|---|---|
| semantic_validity — المعنى | preserved محفوظ / changed متغيّر / ambiguous غامض |
| sentiment_preserved — المشاعر | yes نعم / no لا / uncertain غير متأكد |
| negation_present — وجود نفي لغوي في أي من النصين | yes / no / uncertain |
| negation_affects_sentiment — النفي يؤثر على المشاعر | yes / no / uncertain |

اكتب تعليلًا لكل حالة في `linguistic_notes`. عند وجود نفي، اكتب عبارته في
`negation_cue`، ووصف نطاقه في `original_negation_scope` و
`perturbed_negation_scope`: ما الكلمات أو الفكرة الواقعة تحت النفي؟ وما هدف
المشاعر؟ انتبه إلى النفي باللهجات والتعابير الاصطلاحية والنفي المزدوج. لا
تعتبر وجود كلمة شائعة للنفي إثباتًا لنطاقها أو أثرها.

الواجهة تسجّل وقت آخر تعديل بصيغة ISO 8601 مع المنطقة الزمنية. اضغط
**حفظ القرارات CSV** باستمرار وبعد انتهاء العمل. إغلاق الصفحة يفقد التعديلات
غير المحفوظة. استخدم **استئناف ملف CSV سابق** لمواصلة الملف نفسه. لا تغيّر
نصوص التغريدات أو المعرّفات أو بصمات SHA-256. أكمل جميع الحقول المطلوبة
للحالة التي بدأت مراجعتها؛ يمكن إبقاء الحالات التي لم تبدأها فارغة.

إذا استعملت جدولًا بدل الواجهة، استورد CSV بصيغة UTF-8 مع اعتبار جميع
الأعمدة **نصًا**، بما فيها التغريدات. لا تسمح بتنفيذ محتوى الخلايا كصيغ.
احتفظ باتجاه عرض من اليمين إلى اليسار ولا تغيّر ترتيب أحرف النصوص.

يراجع شخصان الحالات نفسها بصورة مستقلة. تُحسب نسبة الاتفاق وCohen kappa
قبل التحكيم. يحتاج أي خلاف في الخيارات أو وصف نطاق النفي إلى مراجع ثالث
مستقل، يسجّل قرارًا صريحًا مع تعليل بعد قراءة النصين وتعليل المراجعين؛
لا تعرض عليه تنبؤات النموذج. اختلاف صياغة وصف النطاق يُحال أيضًا للتحكيم
احتياطًا. الحالات الغامضة أو المتغيّرة أو غير المكتملة لا تصبح مؤكدة تلقائيًا.

احفظ الملفات في مساحة خاصة ودائمة. لا ترفع نصوص التغريدات أو هويات
المراجعين إلى GitHub العام. يتلقى كل مراجع حزمته فقط.
